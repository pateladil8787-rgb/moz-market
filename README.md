MOZ MARKET v3
Polished Android marketplace prototype for Mozambique.

Includes:
- Cleaner green/black marketplace UI
- Search and categories
- Featured product cards
- Post Ad with up to 10 photos
- Gallery + Camera photo selection
- Category, condition, location, description and WhatsApp fields
- Product details
- Favourites
- My Ads
- Chat/profile UI
- WhatsApp contact button

Important: ads and photos are stored only in app memory in this prototype.
Real online accounts, OTP, database, cloud photo storage and real-time chat require a backend connection.
